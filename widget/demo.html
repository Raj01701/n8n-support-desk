Harbourly is the fictional small SaaS this support desk was built for. The page exists so the chat widget has somewhere real to sit — the bubble in the bottom right is the actual widget, talking to the actual n8n workflow.

Same backend as email

The widget posts to workflow 02, which calls the same answer engine workflow 01 calls for Gmail. One knowledge base, one gate, two doors.

Answers in the same request

No polling and no websocket. The reply comes back in the body of the widget's own POST, and the widget prints how long it took.

Says when it does not know

If nothing in the help centre covers the question, it says so, offers a person, and writes the question down so somebody can write that article.
